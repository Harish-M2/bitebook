# Bitebook temporary brand assets

Premium direction: forest green, champagne gold, warm ivory, charcoal. These are editable SVG files intended as a starting point while the name remains provisional.

## Files
- `logos/app-icon-dark.svg`: dark app icon
- `logos/app-icon-light.svg`: light app icon
- `logos/symbol-*.svg`: transparent symbol variants
- `logos/wordmark-*-horizontal.svg`: horizontal logo lockups
- `logos/wordmark-*-stacked.svg`: stacked lockups
- `icons/`: simple SVG UI icons in green, ivory and gold

## Palette
- Forest green: #0E2F26
- Champagne gold: #D4AF7C
- Ivory: #F8F5ED
- Charcoal: #1A1A1A

## Notes
SVGs are scalable and can be exported to PNG at the exact dimensions required by your app. The logo is a provisional concept, not a trademark or name-clearance check. Review the wordmark and icon at small sizes before shipping.
